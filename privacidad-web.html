1. Funcionamiento de la web

No añadimos cuentas, formularios, cookies publicitarias, píxeles de seguimiento ni herramientas propias de analítica. Las imágenes, estilos y scripts se sirven desde el mismo alojamiento, sin fuentes externas ni vídeos incrustados.

El menú, las preguntas frecuentes y el visor de capturas funcionan en el navegador. «Copiar correo» escribe únicamente nuestra dirección de contacto en tu portapapeles, si el navegador permite esa acción. No leemos su contenido.

2. GitHub Pages y datos técnicos

La web se aloja en GitHub Pages. Para entregar las páginas y proteger su infraestructura, el proveedor puede tratar datos técnicos como la IP, información del navegador y registros de solicitudes conforme a su política de privacidad. La ausencia de analítica propia no equivale a ausencia de registros del alojamiento.

Los enlaces externos no cargan su contenido dentro de esta web. Si los abres, se aplican las condiciones del destino.

3. Cuando nos escribes

El enlace de contacto abre tu aplicación de correo. Si decides enviar un mensaje a dmpstudiodev@gmail.com, recibimos tu dirección y el contenido que compartes para responder a tu consulta.

Conservamos la conversación durante el tiempo necesario para atender la solicitud y las obligaciones aplicables. Puedes escribir a esa misma dirección para pedir información o ejercer tus derechos. No incluyas contraseñas, datos de pago ni información médica o infantil sensible que no sea necesaria.

4. Información específica de las aplicaciones

Las apps tienen funciones y proveedores distintos a los de esta web. Consulta sus documentos para conocer los permisos, compras, publicidad y estadísticas.
